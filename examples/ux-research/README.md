# UX research example

How UX research practitioners do their work, from interviews. **[Open the live map →](https://miguel.design/problem-space-map/)**

| | |
|---|---|
| Hierarchy | 60 tasks, 11 goals, 3 purposes, from practitioner interviews |
| People | Practitioners who raised each task |
| Satisfaction | **Illustrative.** Authored from interview language, not measured. A real map needs a survey. |
| Solutions | 60: 38 products, 22 general tools, each with one sentence per task it serves |

Files:

- `map.json`: the only file the page reads. Assembled by `scripts/build-ux-example.mjs` from research files that are not in this repo.
- Logos: `npm run logos -- examples/ux-research/map.json`.
